打开大屏预览

发布使用 GitHub Contents API，会把 js/bg-data.js、js/broadcast-data.js、data/feed.json.js 等文件提交到仓库，GitHub Pages / Netlify 会自动重新构建。

部署形态说明

  • 纯静态：无后端、无数据库，所有数据都是仓库里的 JS/JSON 文件。
  • 广播实时下发：默认用同源多标签实时同步 + 静态文件；配置远程广播源（GitHub Contents API 地址）后全校大屏自动同步。
  • 语音播报：使用浏览器内置 speechSynthesis，无需联网、无隐私上传。
