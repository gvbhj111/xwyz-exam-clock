## 一、这个版本新增了什么

### 1. 自定义背景轮播（背景来源多元化）

主站背景不再是"一次一张"，而是一个可配置的轮播引擎：

| 来源类型 | 说明 |
| --- | --- |
| 内置图库 | 直接复用 `js/gallery.js` 里的 23 卷 / 542 张校园图（CC BY-NC-SA 4.0） |
| 精选图床 | `js/bg-data.js` 里的短码图床（`ooo.0x0.ooo`） |
| 图床链接 | 后台粘贴任意图片 URL（支持多行批量） |
| 必应每日壁纸 | 自动拉取 `cn.bing.com` 每日一图（带本地缓存，离线自动跳过） |
| 在线随机图 | Picsum / LoremFlickr 等免 key 接口，可按主题词随机 |
| 本地图片 | 把图片放进仓库（如 `./images/`），登记相对路径，换域名也不会坏 |
| 渐变 / 纯色 | 内置 9 套视觉预设，网络全挂时也不会白屏 |
| 动态视频 | 支持 mp4 视频背景（静音循环、自动播放） |
| 自定义 URL | 用户自己的收藏，保存在浏览器本地 |

轮播能力：

- **加权随机**：每个来源可设权重（0 = 不参与），权重越大越容易被抽中；
- **自动切换**：间隔 5 秒 ~ 24 小时可选，页面切到后台自动暂停，省电；
- **过渡与动效**：淡入淡出（可调时长）、Ken Burns 缓慢缩放；
- **画面效果**：原图 / 模糊 / 黑白 / 暖色 / 冷色 / 压暗，遮罩浓度 0-90 可调；
- **防重复**：最近 N 张不重复；
- **容错**：图片加载失败自动换下一张，连续失败自动退化到渐变兜底；
- **用户自助**：大屏右上角「背景」菜单里就能换来源、改间隔、换效果、填自定义图片；
- **可离线**：不依赖 Service Worker（多数图片床不允许自定义响应头），任何静态托管都能跑。

### 2. 考试广播

- **语音播报**：使用浏览器内置 `speechSynthesis`（自动挑选中文语音），可调语速 / 音调 / 音量 / 指定发音人；
- **提示音**：播报前播放内置合成提示音（两音上行），无需音频文件；
- **横幅 + 广播中心**：顶部横幅按级别着色（提示 / 通知 / 重要 / 紧急闪烁），右上角可重播、静音、查看播报记录；
- **考试节点自动播报**：
  - 开考前 30 / 15 / 5 分钟（可配置）
  - 开考时刻
  - 开考后 15 / 30 分钟
  - 结束前 30 / 15 / 5 / 1 分钟
  - 结束时刻
  - 文案模板可改，支持 `{subject}` `{minutes}` `{time}` 变量
- **整点报时**：可选，支持只在考试期间播报；
- **考场纪律轮播**：每 N 分钟播一条自定义纪律提示；
- **外部广播下发**：后台「广播发布」写一条消息，立即在本机所有已打开页面生效（同源多窗口实时同步）；配置远程广播源后，全校大屏自动同步（轮询间隔可调）；
- **系统通知**：可选开启浏览器通知（需要用户授权）；
- **时间校准**：可选接入网络时间接口，修正教室大屏走时；
- **静音开关**：一键静音，状态记在浏览器本地。

### 3. 升级版后台管理（`admin.html`）

深色玻璃风格 + 八个功能页，全部图形化操作，不再需要手改代码：

| 页面 | 能做什么 |
| --- | --- |
| 概览 | 背景来源数、广播条数、考试类型数、语音状态；一键发布 |
| 背景轮播 | 轮播参数（间隔 / 顺序 / 效果 / 遮罩 / 过渡）、来源增删改排序、权重、条目预览、随机预览、恢复默认 |
| 广播发布 | 写广播（级别 / 失效时间 / 固定展示 / 朗读文本）、常用模板、本机试听、广播记录表、清空 / 导出 |
| 自动播报 | 语音设置、考试节点分钟数与文案、整点报时、考场纪律、时间校准 |
| 考试数据 | 可视化编辑 `exam.js`，语法检查（本地沙箱试运行）、考试类型一览表 |
| 站点外观 | 大标题 / 学校 / 版本说明 / 主题色 / 遮罩深度，生成 `js/site-data.js` |
| 发布 | GitHub Token（AES-GCM 加密存本机）、勾选文件逐个提交、下载、Netlify / GitHub Pages 部署说明 |
| 日志 | 全过程日志，可复制 |

其它改进：

- 所有控件**安全绑定**：某个控件缺失不会导致整页脚本崩溃；
- 数据先存浏览器本地，**发布时才生成静态文件**，误操作可恢复；
- 登录状态、验证码、Token 全部只在本机，不上传任何服务器。

## 二、部署（静态托管）

本项目**没有构建步骤**，克隆下来就是可部署产物。

### GitHub Pages

1. 把仓库推送到 GitHub；
2. 仓库 `Settings` → `Pages` → `Source` 选 `Deploy from a branch`；
3. 分支选 `main`，目录选 `/ (root)`，保存；
4. 等 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

> 后台地址是 `<站点地址>/admin.html`。静态站点没有真正的访问控制，请勿公开传播该链接（`robots.txt` 已屏蔽搜索引擎收录）。

### Netlify

1. Netlify → `Add new site` → `Import an existing project` → 选择本仓库；
2. **Build command 留空**，**Publish directory 填 `.`**；
3. 部署完成后访问 Netlify 域名，之后每次 push 到 `main` 会自动同步。

仓库已包含 `netlify.toml`（缓存策略、`data/` 与 `js/` 不缓存以便广播即时生效、后台页加 `noindex`）。

### 其他平台

Cloudflare Pages / Vercel / Gitee Pages / Nginx / IIS / 甚至 `python -m http.server` 都能直接部署：

- 输出目录：仓库根目录
- 构建命令：无
- `file://` 直接打开也能看大屏，但浏览器会限制 `fetch` 读取本地文件，后台建议用本地服务器访问。

### 本地预览

```bash
# 任选一种
python -m http.server 8080
npx serve .
# 然后访问 http://localhost:8080/
```

## 四、日常使用

### 1. 改考试时间

打开 `/admin.html` → 登录 → 「考试数据」：

- 点「加载当前 exam.js」载入；
- 直接改时间（或点「从本地选择文件」载入自己改好的 `exam.js`）；
- 点「语法检查」确认没问题（会解析出所有考试类型）；
- 切到「发布」页勾选 `js/exam.js` → 「发布选中文件」。

### 2. 发一条广播

「广播发布」→ 选级别 → 写正文（可另填更适合朗读的语音文本）→ 「立即广播」。

- 同一台电脑上打开的所有页面立刻响应；
- 想让**全校大屏**都收到，需要配置远程广播源：
  1. 在仓库里准备 `data/feed.json`（首次可用「下载」按钮生成并提交一次）；
  2. 广播源地址填 `https://api.github.com/repos/<用户>/<仓库>/contents/data/feed.json`；
  3. 「发布」页填入 GitHub Token（需要 `repo` 权限），点「保存加密 Token」；
  4. 回到「广播发布」点「保存」→「推送广播到远程」，其它大屏会在轮询间隔（默认 15 秒）内拉取到。

### 3. 换背景来源

「背景轮播」→ 启用 / 停用来源、调权重、排序（↑↓）、「新增来源」、「添加图片 URL」、「登记仓库图片」。

大屏端用户也能自己换：右上角「背景」图标 → 选来源 / 间隔 / 效果 / 自定义图片（这些设置只保存在他自己的浏览器里）。

### 4. 语音播报注意事项

- 浏览器要求**用户先与页面交互**过才允许发声（自动播放策略）。第一次打开大屏时建议先点一下页面（比如点一次「全屏」）；
- 可用语音取决于操作系统，Windows / Android / macOS 一般自带中文语音；
- 若浏览器不支持 `speechSynthesis`，会自动退化为文字横幅提示。

## 六、备份与回滚

改动前的原始版本已经做了三重备份，随时可以退回去：

| 备份方式 | 位置 | 用途 |
| --- | --- | --- |
| Git 分支 | `backup/legacy-7.3.6` | 本地随时切回旧代码 |
| Git 标签 | `backup-7.3.6` | 同上，带说明的里程碑 |
| 压缩包 | `backup/xwyz-exam-clock-7.3.6-original.zip` | 不依赖 Git 的整包快照（可拷贝到U盘） |
| 远程 | `origin/main`（未推送新提交） | 远端仍是旧版本，随时 `git fetch` 找回 |

常用命令：

```bash
# 看一下有哪些备份
git branch -a && git tag

# 只把某个文件退回旧版本
git checkout backup/legacy-7.3.6 -- js/exam.js

# 全部退回旧版本（丢弃当前改动，谨慎）
git reset --hard backup/legacy-7.3.6

# 只是撤销最近一次提交但保留文件
git reset --soft HEAD~1
```

想再生成一次压缩包快照：

```bash
git archive --format=zip --output=backup/snapshot.zip <提交号或分支名>
```
